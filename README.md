# CKA (Certified Kubernetes Administrator) Series

A hands-on Kubernetes learning series focused on the skills required for the Certified Kubernetes Administrator (CKA) exam.

## 🎯 Goal

Build practical Kubernetes administration skills through:

* Kubernetes architecture
* kubectl
* Pods
* Deployments
* Services
* Networking
* Storage
* Scheduling
* Security
* Troubleshooting
* Logging and monitoring
* Cluster maintenance

## 🛠️ Environment

This series uses a Kubernetes cluster for hands-on practice.

Tools:

* Kubernetes
* kubectl
* Docker
* Linux
* YAML

## 🚀 Approach

Each topic contains:

1. Concept
2. Important commands
3. YAML manifests
4. Hands-on practice
5. Troubleshooting scenarios
6. CKA-style tasks

## 📌 Objective

The goal is not only to memorize Kubernetes commands, but to understand how Kubernetes works and become comfortable administering a cluster from the command line.
